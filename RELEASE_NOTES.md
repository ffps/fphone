# Кукуха 1.0.0 — первая версия для тестовой эксплуатации

Это первый выпуск «Кукухи» для тестовой эксплуатации. Проект продолжает развиваться; версия 1.0.0 не означает завершение всех запланированных работ.

## Основные возможности

- Голосовые и видеозвонки между Android-устройствами и браузерным PWA.
- Передача медиа через TURN собственного сервера для работы за мобильным NAT/CGNAT.
- Приём входящих вызовов Android через FCM, PWA — через Web Push.
- Подтверждение получения входящего вызова: гудки контроля посылки вызова начинаются после подтверждения вызываемого устройства.
- Определение занятости обычной мобильной линии Android и короткие гудки занятости у вызывающего клиента.
- Обмен текстовыми сообщениями Android/PWA с подтверждением фактической доставки на каждое устройство.
- Контакты, аватары, локальная история вызовов и диагностические журналы.
- Управление камерой, микрофоном и громкой связью; переключение фронтальной и задней камер.
- Обновлённая иконка «Кукухи» с утверждённым жёлто-зелёным градиентом № 2; исходный силуэт птицы сохранён.

## Состав

- Android-клиент (минимум Android 8.0).
- Браузерный клиент PWA.
- Сервер на Go с SQLite, WebSocket, WebRTC/TURN и push-интеграциями.

Серверный компонент в этом выпуске не менялся относительно версии 0.4.3.

## Известные ограничения

- На отдельных Samsung Galaxy S23 с Android 17 в Samsung Internet может зависать локальное превью камеры PWA; исходящее видео при этом продолжает передаваться собеседнику. Требует дополнительного тестирования.
- Поведение фоновых push-уведомлений зависит от браузера, ОС и настроек энергосбережения устройства.

## Установка и обновление

- Android: установите APK из вложений релиза. Для обновления сохраняйте прежнюю подпись приложения.
- Сервер: обновление серверного бинарного файла для этого выпуска не требуется.
- PWA: обновите статические файлы каталога `pwa/` на сервере; версия кеша Service Worker увеличена.
- Рекомендуется сначала провести тестирование на ограниченной группе пользователей и сохранить резервную копию конфигурации и базы данных сервера.
